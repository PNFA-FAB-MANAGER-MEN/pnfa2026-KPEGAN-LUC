## Sommaire du dépôt

| Dossier | Contenu |
|---|---|
| `docs/` | Fiche projet, cahier des charges, journal quotidien, séquence pédagogique, sécurité, tests, guide de reproduction |
| `hardware/` | CAO, fichiers de découpe laser, FAO, impression 3D, personnalisation, moulage, carte électronique |
| `firmware/` | Micrologiciel de la carte et bancs d'essai |
| `software/` | Protocole applicatif, application, tableau de bord |
| `bom/` | Nomenclature complète chiffrée |

> Les dossiers sans objet pour ce projet sont conservés (exigence ED-03) et signalés ici :
> `hardware/molds/` — sans objet, exemption ET-FAB-06 justifiée dans la fiche projet.
> `hardware/cnc/` — sans objet, aucune opération d'usinage retenue.
