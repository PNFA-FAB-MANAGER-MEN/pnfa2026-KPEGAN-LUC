## Conformité

- [ ] ES-02 — très basse tension seule accessible (≤ 12 V continu) ; bloc secteur certifié du commerce ; batteries lithium protégées et inaccessibles.
- [ ] ES-03 — aucune surface accessible > 45 °C, aucune arête vive ; éléments chauds, mobiles ou fragiles protégés ou signalés.
- [ ] ES-04 — consignes de sécurité élèves dans le plan de séance et pictogrammes sur le dispositif ; aucune infraction machine consignée.
- [ ] ES-05 — aucune donnée personnelle d'élève dans le dépôt ; autorisations versées pour toute photographie de personne.
