## Appris

* **Structures de données en Python :**
* *Listes (`[]`) :* Séquences ordonnées et mutables (possibilité de modifier, remplacer ou réordonner les éléments après création).
* *Tuples (`()`) :* Séquences ordonnées immuables (lecture seule, éléments non modifiables une fois définis).


* **Interactions utilisateur & Conversion de types :**
* La fonction `input()` récupère toujours les saisies sous forme de chaîne de caractères (`str`).
* Le constructeur `int()` permet de convertir (caster) cette saisie en entier pour effectuer des opérations arithmétiques.
* *Exemple :* `age = int(input("Entrez votre âge : "))`


* **Affichage dynamiquement formaté :**
* Syntaxe des f-strings pour injecter directement des variables dans des chaînes de caractères (`f"Mon nom c'est {name}..."`).
* Indexation à partir de $0$ pour extraire un élément précis dans une liste ou un tuple.

## Raté, puis corrigé

* **Problème :** Levée d'une erreur de syntaxe (`SyntaxError: invalid syntax`) lors de l'exécution du script sous Thonny.
* *Cause :* Présence d'une double virgule consécutive (`,,`) lors du passage d'arguments dans la fonction `print("la capitale du Togo est:",, les_villes_du_Togo[0])`.
* *Correction :* Suppression de la virgule superflue dans la ligne de code.
* *Résultat :* Exécution fluide du script et affichage correct dans le Shell.
